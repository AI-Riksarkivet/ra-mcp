Tools

Grouped by source. Every tool returns results as text/markdown; viewer tools also open an interactive app in supporting clients.

Transcriptions & catalogue

  • search_transcribed — Full-text search in AI-transcribed (HTR/OCR) documents
  • search_metadata — Search titles, names, places and descriptions in the catalogue (2M+ records)
  • browse_document — Read page transcriptions by reference code

Document viewer

  • view_document / view_document_urls / view_manifest / view_bild — Open pages with zoomable images and text-layer overlays (by reference code, raw URLs, IIIF manifest, or bild_id)
  • viewer_navigate / viewer_navigate_urls / viewer_go_to_page / viewer_set_highlight / viewer_reopen — Drive an already-open viewer

PDF guides

  • search_guides — Search all Riksarkivet PDF guides at once
  • list_pdfs / display_pdf / search_pdf / read_pdf_page / pdf_go_to_page / pdf_set_search — Open, search and read a PDF in the interactive viewer

Biography & medieval sources

  • search_sbl / view_sbl_article — Svenskt biografiskt lexikon (9,400+ articles)
  • diplomatics_search_sdhk — SDHK medieval charters before 1540 (44,000+)
  • diplomatics_search_mpo — MPO medieval parchment fragments (23,000+)

People registers

  • dds_search_fodelse / dds_search_vigsel / dds_search_doda — Church records: births, marriages, deaths (2.5M records, 1600s–1951)
  • court_search_domboksregister / court_search_medelstad — Court records 1611–1750
  • sjomanshus_search_liggare / sjomanshus_search_matrikel — Seamen's voyages and registrations
  • aktiebolag_search_bolag / aktiebolag_search_styrelse — Joint-stock companies and board members 1901–1935
  • faltjagare_search_faltjagare — Jämtland field regiment soldiers 1645–1901
  • suffrage_search_rostratt / suffrage_search_fkpr — Women's suffrage petition 1913–1914 and FKPR members

Places, vehicles & infrastructure

  • tora_search_tora — Geocode historical places (51,000 settlements, WGS84)
  • rosenberg_search_rosenberg — Rosenberg's geographical lexicon (66,000 places)
  • wincars_search_wincars — Norrland vehicle register 1916–1972 (1.5M vehicles)
  • sj_search_juda / sj_search_ritningar — SJ railway properties and technical drawings

Special collections

  • filmcensur_search_filmreg — Film censorship records 1911–2011 (60,000 films)
  • specialsok_search_fangrullor — Östersund prison records 1810–1900
  • specialsok_search_flygvapen — Military aviation accidents 1912–2007
  • specialsok_search_kurhuset — Hospital patient records 1817–1866
  • specialsok_search_press — Government press conferences 1993–2017
  • specialsok_search_video — Video rental stores 1991–1994

The viewers also expose internal helpers (load_page, load_thumbnails, search_all_pages, get_page_blocks, get_viewer_state, read_pdf_bytes, get_pdf_state, load_sbl_article, get_sbl_state) used by the embedded apps, not meant to be called directly.
